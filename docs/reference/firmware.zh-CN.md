# 固件参考

本文是当前 Open32Drone 固件的实现参考。新用户应先完成
[快速开始](../guide/04-firmware-flight.md)；遇到异常再看
[故障排查](../guide/05-tuning.md)。

## 身份与范围

- 项目名称：Open32Drone（现有固件的构建标识仍为 `minimal`，不是独立产品或分支）；
- 目标：ESP32-S3、Quad-X、四个空心杯电机；
- IMU：编译时选择 FlixPeriph I²C 后端，默认 MPU6500/MPU9250；
- 水平/高度传感器：UART TF-0850 光流/ToF；
- 控制链路：SBUS、专用 Android、ROS 2/MAVROS；
- 升级：USB 完整刷写和仅地面可用的 A/B OTA。

固件不把 QGC 当作飞行控制端，也不包含任务、气压计控制、复杂碰撞分类、MAVLink
直接电机控制、悬停 Trim 或自动参数配置迁移。当前源码有一条实验性后台 HTTP MJPEG
路径；它不进入 300 Hz 循环，也尚不等于硬件/实飞发布证据。标准 MAVLink 参数继续
开放，供 QGC 在地面选择性查看和修改。

## 硬件约定

| 功能 | 外设 | 引脚/配置 |
|---|---|---|
| 编译时选择的 IMU | `Wire` | SDA `GPIO2`、SCL `GPIO43`、400 kHz |
| 状态 LED | GPIO | `GPIO21` |
| 左后电机 | LEDC 通道 1 | `GPIO4` |
| 右后电机 | LEDC 通道 2 | `GPIO3` |
| 右前电机 | LEDC 通道 3 | `GPIO6` |
| 左前电机 | LEDC 通道 4 | `GPIO5` |
| 电池电压 | ADC1 | `GPIO1/A0`，`VBAT_SW` 经 100 kΩ / 100 kΩ 分压 |
| SBUS | `Serial2` | RX `GPIO44`、TX `GPIO9` |
| TF-0850 | `Serial1` | RX `GPIO8`、TX `GPIO7`、115200 8N1 |
| USB 控制台 | `Serial` | 115200 波特率 |

电机 PWM 为 10 kHz、10 bit。四个 LEDC 通道必须全部 attach 成功才能解锁。上锁时
输出为零；解锁后，在飞手或自动控制请求更大推力前，电机怠速为 10%。

### IMU 编译配置

`software/firmware/imu_backend.h` 在编译时选择一个后端。固件有意不在运行时自动探测互不相关的
传感器系列，因为那会让启动、量程、方向和故障处理更难教学，也更难稳定复现。

| 编译值 | 驱动 | 状态 |
|---|---|---|
| `OPEN32DRONE_IMU_MPU9250` | MPU6500/MPU9250/MPU9255 系列 | 默认标准机架配置 |
| `OPEN32DRONE_IMU_ICM20948` | ICM20948 | CI 编译配置；仍需对应硬件台架和飞行验证 |
| `OPEN32DRONE_IMU_MPU6050` | MPU6050 | CI 编译配置；仍需对应硬件台架和飞行验证 |

这些配置向估计器和控制器提供相同的加速度与角速度接口。编译通过只说明接口没有断裂，
不能证明替换后的安装方向、电气连接、校准和飞行参数与标准飞机一致。

## 安装与坐标系

- 机体系采用 FLU：`x` 向前、`y` 向左、`z` 向上；
- IMU 默认旋转为 roll `π`、pitch `0`、yaw `π/2`；
- IMU 可以高于或低于电机平面，但必须刚性固定，并与四电机推力平面平行；
- TF-0850 一体模块垂直向下，位于偏航中心前方 `24 mm`，固件已编译该偏置补偿；
- ROS 发布每架飞机独立的 ENU 变换，例如
  `open32drone/odom -> open32drone/base_link`；只在 MAVLink 边界进行 NED 转换。

## 启动顺序

```text
上电 -> 参数存储 -> LEDC 电机 -> 可选相机内存分配
     -> Wi-Fi/MAVLink/OTA -> 可选相机流
     -> 选定的 IMU 后端 -> SBUS -> TF-0850 -> 陀螺校准 -> 就绪
```

每次冷启动都会重新校准陀螺，不从 NVS 读取。至少需要 500 个样本和两秒静止数据。
初始化期间 LED 亮，setup 完成后熄灭。初始化完成后，滤波电池电压不高于 `3.10 V`
并持续 `1.5 s` 时，GPIO21 才以 `2 Hz` 闪烁；电压不低于 `3.20 V` 并持续 `1.0 s`
后退出。这只是可视提示，不会解锁、降落或切换模式。是否就绪必须看串口状态或客户端
遥测，不能只按 LED 时间判断。

## 模式与控制权

| 自定义模式值 | 名称 | 用途 |
|---:|---|---|
| `2` | 姿态 | 姿态稳定，飞手直接控制油门 |
| `3` | 自动 | 只供内部起飞、降落或已验证 Offboard 使用 |
| `4` | 定高 | 姿态 + ToF 高度/垂直速度控制 |
| `5` | 定点 | 定高 + 光流水平定点 |

模式 `3` 不允许用户直接选择。默认三段 SBUS 开关低/中/高对应 `2/4/5`。

控制优先级是有意的物理 SBUS 输入，其次是当前 Android 或 ROS 租约。接收机仅发送
静态帧不会占用飞机；经过中立观察后，明确摇杆动作才证明飞手意图。物理左下角急停
独立于普通控制权。

## 解锁预检

以下任一项失败都会拒绝解锁：

1. OTA 正在写入；
2. NVS 参数存储不可用；
3. 正在执行加速度计校准；
4. 任一电机 PWM 通道 attach 失败；
5. IMU 没有数据或数据超过 50 ms；
6. 陀螺校准未完成；
7. 姿态或角速度状态无效；
8. 当前所需 RC 映射/链路或 MAVLink 链路无效；
9. 当前有效输入的油门超过 5%；
10. 实测控制循环低于 200 Hz。

Android/ROS 一键起飞原子执行同一套预检，客户端不能再自己复制一套就绪状态机。

## 自动起飞与降落

自动起飞接受 `0.20` 到 `5.80 m` 的相对高度，默认 `0.60 m`。起始推力上限为 20%，
按 `0.45/s` 增长，最大不超过 `ALT_TKO_THR`；高度目标以 `0.40 m/s` 前进，且不超过
实测高度前方 `0.12 m`。TF-0850 的新鲜盲区包也是有效地面证据。

Android 和 ROS 2 使用的 `MAV_CMD_NAV_TAKEOFF` 固定交接到 `POS_HOLD`，命令前左上角
显示什么待机模式都不会改变结果。物理 SBUS 辅助起飞按设计保持不同：它仍返回模式
开关选择的定高或定点模式。

自动控制只拥有垂直方向；起飞和降落全程仍保留实时横滚、俯仰和偏航。定点模式在
光流有效时把水平摇杆转换成速度。光流门暂时不可用或仍在确认时，横滚/俯仰会在相同的
`12°` 定点姿态范围内平滑跟随实时飞手输入；没有实时飞手时平滑回水平，不会因门控切换
进入 `30°` 姿态模式范围。

降落在 `0.30 m` 以上约按 `0.45 m/s` 下降，近地约 `0.28 m/s`，在离地约
`0.14 m` 进入单向 flare；触地后上锁，不再命令回弹。

## 状态估计

选定后端配置为 ±4 g、±2000 deg/s、约 50 Hz 硬件 DLPF 和约 1 kHz 传感器采样率。
飞行估计器只消费加速度和角速度。MPU9250 等后端可能在驱动内部初始化或传输磁力计
数据，但 Open32Drone 不请求磁数据，也没有磁航向融合。偏航来自陀螺积分，只接受
飞手或 Offboard 偏航指令修正。软件加速度低通
`IMU_ACC_LPF_A` 在姿态/高度估计前抑制电机和桨叶振动。

`EST_LVL_WEIGHT` 仍实际使用，并非废参数。落地时重力修正使用 `EST_ACC_WEIGHT`；
飞行中只有当加速度模长和旋转门限确认重力可靠时，才使用更小的
`EST_LVL_WEIGHT`。

TF-0850 会校验 19 字节数据流、新鲜度、积分时间、距离、倾角和速度合理性。水平估计
依次执行延迟陀螺补偿、固定 24 mm 偏航偏置补偿、静止地面偏置学习、尖峰/创新限幅，
最后积分位置。地面偏置收集 30 个有效静止样本后就绪，它是运行状态，不是手工校准参数。
`2.5 m/s` 光流门限只用于拒绝不合理的传感器样本，不是飞行命令速度上限；有效测量不会
再被夹到门控边界。

## 控制循环时序

主循环按固定 `300 Hz` 节拍开始，每轮通过选定后端读取一个 IMU 样本，再依次完成输入、
估计、控制和电机输出。某轮错过截止时间时，只记录迟到并从当前时刻重新建立节拍，不会
连续补跑。因此这里报告的是完整控制迭代，不是空任务自转次数。

| 工作 | 服务频率 |
|---|---:|
| IMU、RC、TF-0850、估计、控制、电机输出 | 每轮，300 Hz |
| MAVLink 命令与遥测调度 | 150 Hz |
| 串口 CLI | 100 Hz |
| OTA 启动确认 | 50 Hz，且只在待确认启动期间有实际工作 |
| 电压、日志、NVS | 保持各模块原有 10/25/1 Hz 内部门限 |

固定节拍让 PID 的 `dt`、传感器到电机的延迟和不同控制端负载更容易复现。后台服务仍远快于
Android 的 25 Hz 手动流和常规 MAVLink 遥测需求。本批次没有修改 PID、估计器权重、
TF-0850 补偿、模式行为或电机映射。

在上锁状态使用：

```text
time
perf reset
# 让待测链路/负载持续运行 10-20 秒
perf
```

`time` 显示最近一秒的循环频率、平均值、p95、p99、最大值、300 Hz 截止时间错过次数、
最大迟到量和超过 5/10 ms 的次数。`perf` 每 16 轮抽样一次，分别显示 IMU 获取、输入、
估计器、控制/电机、串口 CLI、MAVLink/OTA 和后台维护的平均/最大执行耗时；固定节拍的
主动等待不计入阶段执行耗时。它只是低开销诊断器，不是独立飞行任务。至少
分别比较：飞机单独运行、连接 Android、连接 ROS、QGC 打开参数页；这些客户端不能
同时运行。解锁后会拒绝完整参数、日志等重型输出，只保留短状态查询。

以上 RC 端点只是标准遥控配置在 NVS 缺少键时的默认值，不能代替验证。使用 SBUS 时，
每套遥控器仍应执行 `cr`；NVS 中已经保存且有效的端点优先于这些默认值。

ADC 使用校准毫伏值、明确的 11 dB 衰减、10 Hz 采样和参数化低通滤波；换算结果超出
合理 1S 范围 `2.0..4.5 V` 时不发布。剩余电量百分比保持未知，电压也不作为飞行门禁。
新鲜样本按 `clamp(1 + PWR_COMP_SLP × (PWR_COMP_REF - 电压),
1/PWR_COMP_MAX, PWR_COMP_MAX)` 计算倍率；采样关闭/超时或
`PWR_COMP_MAX=1.00` 时倍率为 `1.00`。该倍率只乘到高度 PID 之前的 `ALT_HOVER`。
自动起飞期间，低电压增加量限制在已验证的 `0.49` 前馈，起飞后再以不超过 `0.05/s`
平滑过渡；样本失效时同样平滑回到原始前馈。它不会乘到姿态 PID 修正或最终四路电机
输出，也不改变姿态/直接 Offboard 油门、自动起飞上限和单向降落 flare。独立的 ESP32
brownout 检测仍保持开启。

`pw` 同时打印 GPIO、ADC 原始毫伏、比例、滤波后的电池电压和当前补偿倍率。需要用
万用表校准时，只能在上锁状态按下式调整：

```text
新比例 = 当前 PWR_VOLT_SCALE × 万用表电池电压 / 固件报告电压
```

NVS 中已经明确保存的有效参数仍优先于编译默认值；固件不会偷偷覆盖飞机参数。

## NVS 行为

- 命名空间为 `flix`；
- 缺失键使用编译默认值，不会预先把每个键都写满；
- 有效存储值覆盖默认值，无效值被忽略并打印；
- 最多每秒保存一次，而且只有电机停止时才写 Flash，避免飞行中卡顿；
- `preset` 删除已注册飞行参数并重启，但保留 Wi-Fi 凭据；
- 整片擦除会删除飞行校准和 Wi-Fi 凭据；
- 没有任何代码会偷偷迁移或覆盖旧调参配置。

## MAVLink 接口

固件发布 heartbeat、system/extended state、电池、姿态、IMU、本地位置、距离、RC
通道、电机目标、状态文本、可用/当前模式、参数和日志。接受：

- 解锁/上锁；
- 姿态、定高、定点模式；
- 起飞、降落；
- `MANUAL_CONTROL`；
- 姿态目标；
- 通过 Offboard 预热验证后的本地 NED 位置/速度目标；
- 参数读写和有边界的日志下载。

明确不支持 MAVLink 直接电机命令和任务执行。

远程调参使用标准 `PARAM_REQUEST_LIST`、`PARAM_REQUEST_READ`、`PARAM_SET` 和
`PARAM_VALUE`。它与仅向外发送的 `SERIAL_CONTROL_DEV_SHELL` 诊断文字镜像互相
独立；后者不接收远程 CLI，也不是远程调参依赖，两条路径都予以保留。

每种遥测仍保持已配置频率，但待发消息会按“每个控制循环最多一个计划包”依次发送。
参数列表按每秒 20 个参数发送。日志下载每轮只发一个有界数据包，而且只允许在上锁时
进行；内容是内存 float 日志中实际有效、按时间排列的行。面向人工分析仍以串口
`log dump` 的 CSV 为主。

### 可选 QGC 地面参数编辑

QGC 不属于飞行控制链。兼容目标只是标准 MAVLink 参数页，包括 QGC Android 5.0.3；
本轮仍需要真机验证后，才能声称具体客户端版本已经测试通过。

1. 拆桨，保持飞机上锁且电机停止；
2. 关闭 Android 和 ROS，让手机/电脑连接飞机 Wi-Fi，QGC 监听 UDP `14550`；
3. 等待约六秒，使约 103 个原始参数按 20 个/秒的有界速率下载完成；
4. 搜索并只修改一个命名参数。固件会验证数值并返回实际生效值；解锁后拒绝写参数；
5. 保持上电、电机停止至少两秒，让延迟 NVS 同步完成；重启后重新读取确认。

目前没有 QGC 参数元数据包，所以参数单位、说明、下拉选项和推荐范围可能不显示，含义
与边界以本文为准。禁止用 QGC 解锁、切模式、起飞、降落、执行任务或发送设定值；飞行
必须使用匹配的 Android、ROS 2 或物理 SBUS 链路。

## 失联时间

- RC 帧过期：`150 ms`，并用三帧失联确认；
- MAVLink 手动控制新鲜度：`500 ms`；
- Offboard 设定值超时：`300 ms`；
- 解锁前 MAVLink 心跳/链路健康：`3 s`；
- 可配置输入失联锁存：`SF_RC_LOSS_TIME`，默认 `1 s`；
- 受控推力下降：`SF_DESCEND_TIME`，默认 `5 s`；
- 解锁后 IMU/估计器失效会立即上锁。
- 解锁后机体倾角超过 `70°` 并连续保持 `250 ms`，立即以 `tip-over` 原因上锁；该
  简单保护不使用 ToF 或撞击加速度。

## Wi-Fi 与 OTA

默认 AP：

```text
SSID: open32drone
密码: 12345678
飞机 IP: 192.168.4.1
MAVLink UDP: 14550
OTA HTTP: 8080
```

只能在上锁状态明确选择路由器 STA：

```text
sta LAB_SSID LAB_PASSWORD
reboot
wifi
```

`wifi` 会打印 Android、ROS、图传和 OTA 使用的 DHCP 地址。如果开机 8 秒内 STA
连接失败，固件会打开已保存 AP 作为恢复网络，但不会覆盖 `WIFI_MODE=2`；下次重启
仍会尝试 STA。使用 `ap SSID PASS` 才会永久选择 AP。`preset` 保留 AP/STA 凭据，
完整擦除会删除这些凭据。

每架飞机同一时刻只能由 Android 或 ROS 其中一个 MAVLink 控制端占用；最近一个有效
UDP 发送端会成为
回复对象。实验图传入口是 `GET /stream`，只允许一个观看端，与 OTA 的 HTTP `8080`
互相独立。

接口：

```text
GET  /api/ota/status
POST /api/ota/update
```

更新请求必须在 `X-Firmware-SHA256` 中携带 app 镜像 SHA-256。OTA 只写非活动分区；
解锁、离地、电机运行、自动飞行、Offboard 或当前镜像待验证时都会拒绝。新镜像必须在
验证窗口内保持存储、IMU、陀螺、循环、TF-0850 和 Wi-Fi 健康，否则 bootloader 回滚。
