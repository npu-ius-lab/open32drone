# 固件参考

本页用于查阅固件支持的硬件、引脚接线、飞行模式、参数和通信接口。
第一次使用请从[刷写与首飞](../guide/04-firmware-flight.md)开始；
需要调参或解决飞行问题时，参阅[调参与排查](../guide/05-tuning.md)。

## 硬件与功能 {#身份与范围}

- 主控与机型：ESP32-S3，X 型四旋翼，四个空心杯电机。
- 姿态传感器：通过 I²C 连接 IMU，默认使用 MPU6500/MPU9250。
- 定高与定点：通过 UART 连接 TF-0850 光流/ToF 模块。
- 控制方式：Android 手机、SBUS 遥控器或 ROS 2/MAVROS。
- 固件更新：USB 刷写，或飞机上锁后的 Wi-Fi OTA 更新。

## 接口与引脚 {#硬件约定}

下表列出当前固件的引脚分配。电机位置以机头朝前、从上方观察为准。

| 功能 | 外设 | 引脚/配置 |
|---|---|---|
| IMU | I²C（`Wire`） | SDA `GPIO2`、SCL `GPIO43`、400 kHz |
| 状态 LED | GPIO | `GPIO21` |
| 左后电机 | LEDC 通道 1 | `GPIO4` |
| 右后电机 | LEDC 通道 2 | `GPIO3` |
| 右前电机 | LEDC 通道 3 | `GPIO6` |
| 左前电机 | LEDC 通道 4 | `GPIO5` |
| 电池电压 | ADC1 | `GPIO1/A0`，`VBAT_SW` 经 100 kΩ / 100 kΩ 分压 |
| SBUS | `Serial2` | RX `GPIO44`、TX `GPIO9` |
| TF-0850 | `Serial1` | RX `GPIO8`、TX `GPIO7`、115200 8N1 |
| USB 控制台 | `Serial` | 115200 波特率 |

电机使用 10 kHz、10 bit 的 PWM 输出。四路 PWM 均初始化成功后才能解锁。
上锁时电机停止；解锁后的最低输出为 10%，随后按摇杆或自动控制指令增加推力。

### 选择 IMU 型号 {#imu-编译配置}

IMU 型号在 `firmware/imu_backend.h` 中设置，编译后生效。

| 编译值 | 驱动 | 状态 |
|---|---|---|
| `OPEN32DRONE_IMU_MPU9250` | MPU6500/MPU9250/MPU9255 系列 | 默认配置 |
| `OPEN32DRONE_IMU_ICM20948` | ICM20948 | 已纳入自动编译检查，尚需实机验证 |
| `OPEN32DRONE_IMU_MPU6050` | MPU6050 | 已纳入自动编译检查，尚需实机验证 |

更换 IMU 后，还需要核对接线和安装方向，重新校准，并完成拆桨检查后再进行飞行测试。

## 安装与坐标系

- 机体系采用 FLU：`x` 向前、`y` 向左、`z` 向上；
- IMU 默认旋转为 roll `π`、pitch `0`、yaw `π/2`；
- IMU 可以高于或低于电机平面，但必须刚性固定，并与四电机推力平面平行；
- TF-0850 光流/ToF 模块垂直向下，位于偏航中心前方 `24 mm`，固件会补偿这一安装偏移；
- ROS 发布每架飞机独立的 ENU 变换，例如
  `open32drone/odom -> open32drone/base_link`；与 MAVLink 通信时转换为 NED 坐标。

## 启动顺序

[![启动顺序](/media/figures/boot-sequence.svg)](/media/figures/boot-sequence.svg)

每次冷启动都会重新校准陀螺，不从 NVS 读取。至少需要 500 个样本和两秒静止数据。
初始化期间 LED 亮，setup 完成后熄灭。初始化完成后，滤波电池电压不高于 `3.10 V`并持续 `1.5 s` 时，GPIO21 才以 `2 Hz` 闪烁；电压不低于 `3.20 V` 并持续 `1.0 s`后退出。

## 飞行模式与控制切换 {#模式与控制权}

| 自定义模式值 | 名称 | 用途 |
|---:|---|---|
| `2` | 姿态 | 姿态稳定，飞手直接控制油门 |
| `3` | 自动 | 自动起飞、降落或已激活的 Offboard 控制 |
| `4` | 定高 | 姿态 + ToF 高度/垂直速度控制 |
| `5` | 定点 | 定高 + 光流水平定点 |

模式 `3` 不允许用户直接选择。默认三段 SBUS 开关低/中/高对应 `2/4/5`。

物理遥控器的主动操作优先于 Android 或 ROS。接收机仅仅保持连接、持续发送相同的中立摇杆数据，不会接管飞机；固件先确认摇杆回中，再根据后续摇杆动作判断是否接管。
遥控器急停始终有效，不受当前控制方式影响。

## 解锁前检查 {#解锁预检}

以下任一项失败都会拒绝解锁：

1. OTA 正在写入；
2. NVS 参数存储不可用；
3. 正在执行加速度计校准；
4. 任一电机 PWM 通道初始化失败；
5. IMU 没有数据或数据超过 50 ms；
6. 陀螺校准未完成；
7. 姿态或角速度状态无效；
8. 当前所需 RC 映射/链路或 MAVLink 链路无效；
9. 当前有效输入的油门超过 5%；
10. 实测控制循环低于 200 Hz；
11. 控制循环看门狗未能正常启动或已检测到故障。

Android 和 ROS 发送一键起飞命令后，由固件统一完成这些检查。
检查不通过时，固件会拒绝起飞并返回原因。

## 自动起飞与降落

自动起飞接受 `0.20` 到 `5.80 m` 的相对高度，默认 `0.60 m`。起始推力上限为 20%，按 `0.45/s` 增长，最大不超过 `ALT_TKO_THR`；高度目标以 `0.40 m/s` 前进，且不超过实测高度上方 `0.12 m`。起飞前，TF-0850 的有效盲区数据包可用于检查传感器是否在线。
降落过程中，若刚刚测到近地距离，随后进入盲区，固件会结合低推力、低垂直速度和持续静止状态判断落地；近地记录最多保留 1 秒。
上锁停机后，新鲜的盲区包与持续静止状态也可恢复地面确认。传感器断线、IMU 数据过期或在高处突然失去测距，都不能仅凭“没有距离”认定落地。

Android 和 ROS 2 使用的 `MAV_CMD_NAV_TAKEOFF` 在起飞后进入定点模式 `POS_HOLD`，不受起飞前客户端显示模式的影响。使用 SBUS 遥控器辅助起飞时，起飞后进入模式开关所选的定高或定点模式。

正常自动起飞和降落只接管垂直运动，飞手仍可用摇杆调整横滚、俯仰和偏航。进入失联保护后，不再跟随网络摇杆指令。

定点模式下，光流数据有效时，水平摇杆控制移动速度。光流数据暂时不可用时，摇杆改为直接调整横滚和俯仰，最大倾角仍为 `12°`；没有有效摇杆输入时，飞机逐渐回到水平。

降落在飞机高度处于 `0.30 m` 以上约按 `0.45 m/s` 下降，近地约 `0.28 m/s`，在离地约`0.14 m` 进入着陆收油阶段，此后推力只减不增。测距、垂直速度、推力和惯性传感器数据连续至少 `300 ms` 满足接地条件后，才结束降落。

## 状态估计

IMU 配置为 ±4 g 加速度量程、±2000 deg/s 角速度量程、约 50 Hz 硬件低通滤波和约1 kHz 采样率。固件使用加速度和角速度估计姿态，不使用磁力计进行航向校正。

TF-0850 每帧数据为 19 字节。固件检查数据是否及时、距离和倾角是否有效、速度是否合理，再根据水平速度估算位置。突变数据会被过滤，单次估计修正也有限幅。

飞机在地面静止时，固件收集 30 个有效样本，自动估算光流零偏，无需手工校准。同一次开机中，已测得的零偏不会因重新解锁而清空。使用零偏回退值时，日志中的`flowBiasFallback` 会标记这一状态；此时水平倾角修正限制为 `3°`，并暂停速度误差积分。

## 控制循环时序

主循环按固定 `300 Hz` 节拍开始，每轮读取一个 IMU 样本，再依次完成输入、估计、控制和电机输出。某轮错过截止时间时，只记录迟到并从当前时刻重新建立节拍，不会连续补跑。`time` 显示的频率是每秒完整执行这些步骤的次数。

独立高优先级定时器监视解锁后的完整循环：超过 `100 ms` 没有完成一轮，先停止四路 LEDC PWM，再重启。`sys` 显示看门狗初始化状态；该保护的真实停桨时序仍需拆桨台架故障注入验证。

| 工作 | 服务频率 |
|---|---:|
| IMU、RC、TF-0850、估计、控制、电机输出 | 每轮，300 Hz |
| MAVLink 命令与遥测调度 | 150 Hz |
| 串口 CLI | 100 Hz |
| OTA 启动确认 | 50 Hz，且只在待确认启动期间有实际工作 |
| 电池电压采样 | 10 Hz |
| 飞行日志记录 | 解锁时 25 Hz |
| NVS 参数保存 | 最多 1 Hz，仅在电机停止时写入 |

固定频率使控制器按稳定的时间间隔计算。串口、MAVLink 等服务按各自频率执行，
避免通信和诊断输出长时间占用飞行循环。

在上锁状态使用：

```text
time
perf reset
# 让待测链路/负载持续运行 10-20 秒
perf
```

`time` 显示最近一秒的循环频率、平均值、p95、p99、最大值、300 Hz 截止时间错过次数、最大迟到量和超过 5/10 ms 的次数。`perf` 每 16 轮抽样一次，分别显示 IMU 获取、输入、估计器、控制/电机、串口 CLI、MAVLink/OTA 和后台维护的平均/最大执行耗时；固定节拍的主动等待不计入执行耗时。排查性能问题时，可分别记录飞机单独运行、连接 Android、连接 ROS、QGC 打开参数页这几种情况，每次只连接一个客户端。

解锁后不允许打印完整参数列表或导出日志，只保留简短状态查询。

### 电池电压与推力补偿

ADC 每秒采样 10 次，使用校准后的毫伏读数，衰减设置为 11 dB，并进行低通滤波。换算后的电池电压不在 `2.0..4.5 V` 范围内时，不发布该读数。固件不估算剩余电量百分比；低电压会触发 LED 提示，但不会自动阻止解锁或触发降落。

有效电压数据按 `clamp(1 + PWR_COMP_SLP × (PWR_COMP_REF - 电压),
1/PWR_COMP_MAX, PWR_COMP_MAX)` 计算倍率；采样关闭/超时或
`PWR_COMP_MAX=1.00` 时倍率为 `1.00`。该倍率只乘到高度 PID 之前的 `ALT_HOVER`。

`pw` 同时打印 GPIO、ADC 原始毫伏、比例、滤波后的电池电压和当前补偿倍率。需要用万用表校准时，只能在上锁状态按下式调整：

```text
新比例 = 当前 PWR_VOLT_SCALE × 万用表电池电压 / 固件报告电压
```

已保存的有效参数优先于编译默认值。只要没有擦除 NVS，重新编译并刷入固件也会保留这些值。

## 参数保存与恢复 {#nvs-行为}

参数和校准数据保存在板载 Flash 的 NVS 存储区，断电后仍保留。
串口 `p NAME VALUE`、地面 MAVLink `PARAM_SET`、`ca`、`cr` 和 `ap`/`sta` 会保存对应设置。
开机测得的陀螺零偏、光流零偏、控制器积分和飞行目标只在本次运行中使用，不保存为调参值。

- 参数保存在 NVS 的 `flix` 命名空间中；
- 没有保存过的参数使用编译默认值；
- 已保存的有效值优先使用；无效值会被忽略，并在串口提示；
- 最多每秒保存一次，而且只有电机停止时才写 Flash，避免飞行中卡顿；
- `preset` 清除固件管理的飞行参数并重启，但保留 Wi-Fi 设置；
- 整片擦除会删除飞行参数、校准数据和 Wi-Fi 设置；
- 升级固件不会自动转换旧参数，新旧版本的参数差异需要按更新说明处理。

## MAVLink 接口

固件发布 heartbeat、system/extended state、电池、姿态、IMU、本地位置、距离、RC 通道、电机目标、状态文本、可用/当前模式、参数和日志。接受：

- 解锁、地面普通上锁及明确急停（`param2=21196`）；
- 姿态、定高、定点模式；
- 起飞、降落；
- `MANUAL_CONTROL`；
- 姿态目标；
- 持续发送设定值、完成 Offboard 启动检查后的本地 NED 位置/速度目标；
- 参数读写和分包日志下载。

普通上锁在空中或地面状态不明时返回 `DENIED`，需要降落时使用 `LAND`。Offboard 激活时，普通 `MANUAL_CONTROL` 不会自动接管，须先明确切换回飞手模式。ROS 偏航角速度遵循 ENU 正方向：正值为逆时针，由 MAVROS 转换为 NED，再由固件转换回内部坐标。

远程调参使用标准`PARAM_REQUEST_LIST``PARAM_REQUEST_READ`、`PARAM_SET` 和
`PARAM_VALUE`。它与仅向外发送的`SERIAL_CONTROL_DEV_SHELL` 诊断文字镜像互相独立。后者只向客户端发送诊断文字，不接受远程串口命令；查看和修改参数不依赖它。

每种遥测仍保持已配置频率，但待发消息会按“每个控制循环最多一个计划包”依次发送。
参数列表按每秒 20 个参数发送。日志下载每轮发送一个数据包，只能在上锁时进行。
日志来自内存缓冲区，按记录时间排列。需要在电脑上分析时，可以用串口`log dump` 导出 CSV。

### 可选 QGC 地面参数编辑

QGC 可通过标准 MAVLink 参数接口查看和修改参数。

1. 拆桨，保持飞机上锁且电机停止；
2. 关闭 Android 和 ROS，让手机/电脑连接飞机 Wi-Fi，QGC 监听 UDP `14550`；
3. 等待约六秒，接收约 103 个参数，传输速度为每秒 20 个；
4. 搜索并只修改一个命名参数。固件会验证数值并返回实际生效值；解锁后拒绝写参数；
5. 保持上电、电机停止至少两秒，让延迟 NVS 同步完成；重启后重新读取确认。

## 失联与故障保护 {#失联时间}

- RC 数据超时：`150 ms`，连续三帧失联后确认；
- MAVLink 摇杆数据超时：`500 ms`；
- Offboard 设定值超时：`300 ms`；
- 解锁前要求最近 `3 s` 内收到有效 MAVLink 数据；
- 控制输入失联持续 `SF_RC_LOSS_TIME`（默认 `1 s`）后进入保护；
- 有有效 ToF 测距时，失联保护执行定高降落，并检查是否接地。没有有效测距时，在 `SF_DESCEND_TIME`（默认 `5 s`）内逐步减小推力，时间到后停机；此时不代表已经确认落地。
- IMU 读取失败或数据出现 NaN、无穷值时，该次数据会被丢弃并计数。超过 `50 ms` 没有有效样本，或姿态/角速度估计无效时，立即上锁。`imu` 可查看错误次数和最大样本间隔。
- ToF 失效时保留的高度标记为 `heightValid=0`，垂直速度按实际时间衰减；`groundConfirmed` 单独记录接地判断。
- 解锁后机体倾角超过 `70°` 并连续保持 `250 ms`，立即以 `tip-over` 原因上锁；该简单保护不使用 ToF 或撞击加速度。

## Wi-Fi 与 OTA

默认 AP：

```text
SSID: open32drone
密码: 12345678
飞机 IP: 192.168.4.1
MAVLink UDP: 14550
OTA HTTP: 8080
```

需要让飞机连接路由器时，在上锁状态设置 STA 模式：

```text
sta LAB_SSID LAB_PASSWORD
reboot
wifi
```

`wifi` 会打印 Android、ROS、图传和 OTA 使用的 DHCP 地址。如果开机 8 秒内 STA连接失败，固件会打开已保存 AP 作为恢复网络，但不会覆盖 `WIFI_MODE=2`；下次重启仍会尝试连接路由器。使用 `ap SSID PASS` 可改回默认使用飞机热点。`preset` 保留 Wi-Fi 设置，完整擦除会删除这些设置。

每架飞机同一时刻只连接一个 Android 或 ROS 控制端。固件收到有效的控制端心跳后，记录它的 IP 和 UDP 端口，并向该地址回复。飞机解锁后不更换回复地址；上锁后，原控制端超过 `3 s` 没有发送有效数据，才可由新控制端的心跳切换地址。

实验图传入口为 `GET /stream`，一次只允许一个观看端，与 OTA 的 HTTP `8080` 服务独立。

OTA 接口：

```text
GET  /api/ota/status
POST /api/ota/update
```

更新请求需在 `X-Firmware-SHA256` 中提供应用固件的 SHA-256 校验值。
固件使用 A/B 两个应用分区，OTA 将新固件写入当前未运行的分区。
飞机解锁、离地、电机运行、正在自动飞行或使用 Offboard 时，均不允许更新；当前固件还在启动检查期间，也不能再次更新。

更新后重启，固件会检查参数存储、IMU、陀螺校准、控制循环、TF-0850 和 Wi-Fi。只有在规定时间内通过检查，新固件才会被确认使用；检查未通过时，启动程序会恢复上一版固件。
