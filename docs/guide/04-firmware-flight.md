# 03 · 固件刷写与首飞

组装好飞机后，先取下桨叶，刷写固件并完成起飞前检查，再用 Android 手机首飞。按这套步骤操作，不需要遥控器，也不用安装 ROS 或开发环境。

## 3.1 下载固件和 APK {#downloads}

打开 [GitHub Releases](https://github.com/npu-ius-lab/open32drone/releases)，在同一 Release 中下载 **完整固件 full.bin** 和 **Android APK**。固件放在电脑上，APK 下载到手机上。

| 文件 | 用途 |
|---|---|
| `Open32Drone-20260928-190250-full.bin` | 首次安装，通过 USB 写入地址 `0x0` |
| `Open32Drone-20260928-190250-android.apk` | 安装到 Android 8.0 及以上手机 |
| `Open32Drone-20260928-190250-app.bin` | 以后通过 APK 做 OTA 升级时使用，首次刷写不用它 |

下载后用同一 Release 附带的 `SHA256SUMS` 核对文件完整性。确认固件与你的主控和 IMU 匹配后再刷写。

## 3.2 固件刷写 {#flashing}

推荐用电脑上的 **Chrome 或 Edge** 打开 [Espressif 网页刷写工具](https://espressif.github.io/esptool-js/)。Windows、macOS 和 Linux 都可以使用，但 Safari 和 Firefox 不支持这种刷写方式。使用网页工具不需要安装 Python、Arduino IDE 或 ESP-IDF。

### 连接飞机

1. 取下桨叶，用 USB-C **数据线** 连接电脑和 XIAO。
2. 按住 **BOOT**，按一下 **RESET**，再松开 **BOOT**，进入下载模式。
3. 网页 **Program** 区域的 Baudrate 选择 `460800`，点击 **Connect**，选择 XIAO 对应的串口。标准 XIAO 不要勾选 `WebUSB (CH340)`。

![Espressif 网页刷写工具：在 Program 区域选择波特率并连接串口](/media/figures/web-flasher.png)

上图是连接前的界面。连接成功后会出现固件文件和刷写地址设置。

### 选择文件并刷写

连接成功后，按下表设置。首次安装先点击 **Erase Flash** 并等待擦除完成；它会清除已有校准、参数和 Wi-Fi 设置。

| 网页项目 | 设置 |
|---|---|
| File | 选择下载的 `Open32Drone-20260928-190250-full.bin` |
| Flash Address | **`0x0`**，不要保留网页初始的 `0x1000` |
| Flash Mode / Frequency / Size | 选择 `keep`，保留固件镜像内的设置 |

点击 **Program**，等待写入和校验成功。点击 **Disconnect** 释放串口，再按一次 RESET 正常启动。刷写失败时不要继续起飞；无法使用网页工具时，再看[可选的命令行方法](../reference/source-build.zh-CN.md#usb-刷写)。

| 遇到的问题 | 先这样处理 |
|---|---|
| 没有串口可选 | 换确认能传数据的线，直连电脑 USB，再进入下载模式 |
| 串口被占用 | 关闭其他串口软件或占用串口的浏览器标签 |
| 一直 Connecting 或写入中断 | 重新进入下载模式；把波特率改成 `115200` 再试 |
| Linux 提示权限不足 | 按发行版设置串口权限；Ubuntu 通常需把用户加入 `dialout` 组后重新登录 |

## 3.3 起飞前准备 {#preflight}

### 打开串口工具

推荐 [CoolTerm](https://freeware.the-meiers.org/#CoolTerm)，下载对应电脑系统的版本。保持 USB 连接，关闭刷写网页的串口连接，在 CoolTerm 的 **Options** 中设置：

| 设置项 | 值 |
|---|---|
| Port | XIAO 正常启动后的串口；Windows 常见 `COM…`，macOS 常见 `usbmodem…` |
| Baudrate | `115200` |
| Data Bits / Parity / Stop Bits | `8 / None / 1` |
| Flow Control | 不启用 |
| Terminal Mode | `Line Mode` |
| Enter Key Emulation | `LF` |

点击 **Connect**，在底部输入框中输入命令后回车。按一次 RESET，让飞机水平静置，等待 `Gyro calibration complete` 和 `Initializing complete`。工具设置详见 [CoolTerm 帮助](https://freeware.the-meiers.org/CoolTermHelp/)。

刷写和校准都通过 **USB 串口** 完成，电脑不用连接飞机热点。下一节用手机起飞时再连接热点。

### 检查传感器

每次输入一条命令，回车后查看结果：

| 命令 | 看什么 |
|---|---|
| `sys` | 固件标识为 Open32Drone，主循环约 300 Hz |
| `imu` | 传感器状态正常；静置后 `gyro calibrated: 1` |
| `flow` | 数据包持续更新；将飞机平稳抬到 20–60 cm，测距随高度变化 |
| `pw` | 电池电压有读数，随后与万用表校准 |

检查时保持拆桨。飞机贴近地面时，ToF 可能处于近距离盲区；起飞时仍应平放地面，不要手托飞机解锁。

### 六面加速度计校准

第一次装机、更换 IMU 或完整擦除后，运行 `ca`。按照串口提示依次放置：

1. 水平；
2. 机头向上；
3. 机头向下；
4. 右侧着地；
5. 左侧着地；
6. 倒置。

每次摆好后松手，让飞机静止放在刚性平面上采样。出现 `Accelerometer calibration accepted` 后，把飞机恢复水平，等待陀螺校准再次完成，再执行 `imu`。静止时加速度模长应接近 `9.81 m/s²`。

### 电池电压校准

保持拆桨，接上电池。用万用表测量电池端电压，记为 `V_DMM`；运行 `pw` 读取飞控显示电压，记为 `V_FW`。先运行 `p PWR_VOLT_SCALE` 读取现值，再计算：

```text
新比例 = 旧比例 × V_DMM ÷ V_FW
```

写入后等待一秒，再用 `pw` 检查：

```text
p PWR_VOLT_SCALE 你的新数值
```

例如旧比例为 2.000，万用表为 4.10 V，飞控为 4.00 V，新比例就是 `2.000 × 4.10 ÷ 4.00 = 2.050`。


### 检查电机

飞机保持上锁、拆桨，每次只发送一条命令：

| 命令 | 应转动的电机（从机顶看） |
|---|---|
| `mrl` | 后左 M0 |
| `mrr` | 后右 M1 |
| `mfr` | 前右 M2 |
| `mfl` | 前左 M3 |

每次只有对应电机低速转动约 1 秒。位置或转向不对，先按[电机方向图](03-hardware.md#motor-layout)排查。确认四个电机后断电，再按[装桨说明](03-hardware.md#propellers)安装对应桨叶。

校准会保存在飞机上，正常重启不需要重复做。完整擦除后重新校准；只用手机不需要执行遥控器校准 `cr`。详细保存规则见[参数保存与恢复](../reference/firmware.zh-CN.md#nvs-行为)。

## 3.4 用 Android 手机首次起飞 {#android-first-flight}

### 安装和连接

1. 在手机上安装本章下载的 APK，按系统提示允许该来源安装应用。
2. 飞机接上电池，平放在光照均匀、有纹理的地面，周围留出至少 2 m 空间。起飞前拔掉 USB 数据线。
3. 手机连接 Wi-Fi **`open32drone`**，密码 **`12345678`**。提示“无互联网”时选择继续连接。
4. 打开 Open32Drone 应用。若改过地址，在 **工具 → 飞机地址** 中设为 **`192.168.4.1`**。等左上角的连接状态更新；手机连上 Wi-Fi，还不代表应用已经连上飞控。

首次使用保持飞机热点直连，不必先配置路由器。关闭 ROS 和其他 MAVLink 客户端，使用过程中保持 APK 在前台。

### 认识操作区

| 位置 / 按钮 | 用途 |
|---|---|
| 左上角连接状态和模式 | 确认收到飞控数据；模式显示的是飞机当前状态 |
| 下方中央的高度输入框 | 首飞使用 `0.65` m |
| **长按定点起飞** | 自动完成预检、解锁、爬升和定点保持 |
| **长按降落** | 自动下降，落地后停桨 |
| **紧急上锁** | 立即停桨，不是正常降落按钮 |
| 左摇杆 | 升降和转向 |
| 右摇杆 | 前后和左右移动 |

发出紧急上锁请求后，状态栏先显示请求已发送。收到命令确认后，还要等飞机反馈已上锁（未武装）。如果显示“未确认”，不能认定桨叶已经停转。关闭 App 时不会补发摇杆指令，控制流中断由飞控处理。

以上是当前 APK 中的按钮名称。“长按定点起飞”会自动进入定点，不需要先单独解锁或切换模式。

### 起飞、悬停和降落

1. 输入高度 `0.65`，长按 **“长按定点起飞”** 约 0.6 秒。
2. 松开摇杆，先观察约 5 秒悬停；状态平稳后再小幅尝试前后左右移动。
3. 长按 **“长按降落”**，等待飞机接地、四个电机全部停转，再断电。

若出现明显倾斜、持续抖动或快速漂移，及时降落。即将碰人、缠绕或无法正常控制时，长按 **“紧急上锁”**；这会直接停桨，空中的飞机会下落。

按钮变灰时先看顶部提示，检查连接状态、飞机地址和是否有其他控制端占用；不要反复点击起飞。遇到问题按[调参与排查](05-tuning.md)处理。

## 3.5 可选：使用遥控器 {#sbus}

手机已经能完成首飞。只有准备使用实体摇杆时，才需要购买匹配的 SBUS 接收机和遥控器。

接收机按[组装说明](03-hardware.md#xiao-与接收机)连接。关闭 APK 和 ROS，取下桨叶后校准。

### 连接与校准

安装了接收机时，打开遥控器并运行 `cr`。完成串口给出的八个摇杆和开关动作，然后用 `rc` 查看结果：

| 操作 | 正常读数 |
| --- | --- |
| 横滚、俯仰、偏航回中 | 接近 0 |
| 油门最低 / 最高 | 接近 0 / 1 |
| 三段模式开关 | 接近 0 / 0.5 / 1 |

只用 Android 或 ROS 的飞机不需要执行 `cr`。


### 遥控起降

三段开关对应三个模式：

| 开关位置 | 模式 | 操作感觉 |
| --- | --- | --- |
| 低 | STAB 姿态 | 油门直接控制推力，适合熟练飞手 |
| 中 | ALT_HOLD 定高 | 油门回中保持高度 |
| 高 | POS_HOLD 定点 | 光流保持水平位置，首飞推荐 |

把三段开关拨到高档定点。油门最低、偏航最右完成解锁，电机会以约 10% 怠速转动。将油门保持在 62.5% 以上约 0.2 秒，飞机进入辅助起飞并爬升到默认 0.60 m。起飞后让油门回到中位，小幅修正水平位置。

降落时把油门保持在 5% 以下约 0.3 秒，飞机会自动下降并在接地后停桨。需要取消下降时将油门推到 60% 以上。

急停动作是油门最低、偏航最左保持至少 150 ms。急停会立即停桨，飞机在空中会直接下落，因此只在即将碰人、缠绕或姿态失控时使用。


## 3.6 可选：连接路由器 {#router}

熟悉手机直连后，如果需要让电脑保持互联网连接，或想接入实验室网络，可以改用路由器 STA 模式。让飞机、Android 手机和 ROS 2 电脑接入同一个局域网，就不用在飞机热点和实验室网络之间来回切换。第一次配置仍通过 USB 串口完成，过程中保持拆桨和上锁。

准备一个飞机能够连接的 2.4 GHz Wi-Fi。SSID 长度为 1–32 个字符，密码长度为
8–63 个字符。打开 115200 波特率串口，先查看当前状态：

```text
wifi
```

默认完整镜像会显示 AP 模式和地址 `192.168.4.1`。把下面的示例名称和密码替换为路由器
的实际参数：

```text
sta LAB_SSID LAB_PASSWORD
reboot
```

`sta` 会保存路由器凭据并把启动模式设为 STA；运行中的网络不会立即切换，执行 `reboot`
后才生效。飞机重新启动后继续通过 USB 串口执行：

```text
wifi
```

连接成功时应看到以下关键字段：

```text
Configured mode: STA (2)
Mode: Client (STA)
Connected: 1
SSID: LAB_SSID
IP: <路由器分配的飞机地址>
MAVLink UDP: bound 1 local 14550
```

`IP` 由路由器 DHCP 分配，以飞机实际打印的地址为准。手机或 ROS 2 电脑接入同一路由器后，
先测试该地址是否可达：

```bash
printf '请输入 wifi 命令显示的飞机 IP：'
read -r AIRCRAFT_IP
ping -c 3 "$AIRCRAFT_IP"
```

建议在路由器管理页面按飞机的 Wi-Fi MAC 地址设置 DHCP 地址保留，使飞机每次上电都获得
相同地址；同时关闭会阻止局域网设备互访的访客网络或客户端隔离。真实 SSID 和密码只写入
飞机，不写入项目源码、教程或飞行日志。

Android 打开 **工具 → 飞机地址**，填入 `wifi` 输出的 `IP`。需要编程控制时，再按 [ROS 2 教程](06-ros.md)配置电脑；同一时刻只使用 Android 或 ROS 2 其中一个控制端。

如果飞机在启动后的 8 秒内没有连上路由器，会自动开启已保存的飞机热点作为恢复入口。
串口中的 `wifi` 会显示 `Mode: Access Point (AP) - STA fallback`。修正路由器名称或密码后
重新执行 `sta ...` 和 `reboot`；需要永久恢复直连模式时执行：

```text
ap open32drone 12345678
reboot
```


熟悉基础飞行后，如果想用程序控制飞机，继续看 [ROS 2 控制](06-ros.md)。
